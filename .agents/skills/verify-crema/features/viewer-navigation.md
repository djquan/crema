# Viewer navigation

## Sub-features

- Enter and double-click open the viewer
- Left and Right change photos
- Escape returns to the same grid selection
- Viewer image has a useful accessible name

## How to get to it (user POV)

Select a thumbnail, then press Enter or double-click it.

## Driving it with Computer Use

Use the focused thumbnail and press Enter. Fetch fresh state and find `Preview of <filename>`. Press Right and confirm the name changes. Press Escape and confirm the selected grid item matches the last viewer item. Repeat once with a double-click. Capture evidence after each transition.

## Gotchas

The viewer may show a cached thumbnail before its larger preview arrives. Confirm the selected photo, not just that an image node exists. Fit and 100% operate on the decoded preview, not the untouched full-resolution source.
